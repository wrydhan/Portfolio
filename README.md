# Resume Website

A dark, automotive-inspired portfolio and resume site built with Next.js, Tailwind CSS, and Framer Motion. Designed for deployment on [Vercel](https://vercel.com).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize Your Content

Edit **`src/data/resume.ts`** with your name, experience, projects, skills, and links. Drop your PDF resume into `public/resume.pdf` to enable the download link.

## Deploy to Vercel

1. Push this repo to GitHub
2. Import the project at [vercel.com/new](https://vercel.com/new)
3. Vercel auto-detects Next.js — click Deploy

No extra configuration needed.
